## 1. 보고서의 핵심 관점

이번 결과보고서는 “사이트의 모든 기능이 완성되었다”는 보고서가 아니라, **3개월 PoC를 통해 DemoStatra가 KOAA SHOW의 전시회/B2B 매칭 업무에서 어떤 가능성과 한계를 확인했는지**를 정리하는 문서로 작성한다.

핵심 메시지:

> DemoStatra는 KOAA SHOW 참가기업/전시회 데이터를 AI 매칭 가능한 AX 데이터 프로필로 전환하고, 공개 웹 데이터와 결합하여 해외 바이어 후보를 탐색·추천하는 가능성을 검증했다. 다만 실제 운영 수준으로 확장하기 위해서는 참가기업 데이터 품질 보완, 매칭 근거 고도화, 담당자 업무 플로우 연계, 에이전트별 백엔드 기능 안정화가 필요하다.

## 2. 보고서에 반드시 들어갈 내용

### 2.1 PoC 배경

- KOAA SHOW는 자동차/부품/모빌리티 관련 전시회로 B2B 매칭 수요가 존재한다.
- (재)아인글로벌 B2B 담당자들이 DemoStatra 사이트와 AI 매칭 개념을 실제 PoC 형태로 검토했다.
- 기존 전시회 데이터는 참가기업명, 부스, 카테고리, 연락처, 홈페이지 등 기본 디렉토리 수준인 경우가 많다.
- AI가 의미 있는 매칭을 하기 위해서는 단순 디렉토리를 AX 데이터 프로필로 바꾸는 과정이 필요하다.

### 2.2 PoC 기간 및 범위

- 기간: 2026년 4월 ~ 6월
- 범위:
  - DemoStatra 사이트 기반 B2B 매칭 기능 검토
  - 참가기업/바이어 데이터 활용 가능성 검토
  - AX 데이터 프로필 개념 정리
  - AI 기반 해외 바이어/파트너 추천 가능성 확인
  - B2B 담당자 관점의 실무 적용 가능성 검토

### 2.3 현재 사이트 작동 상태

별도 문서 참조:

- `D:/demostatra-project/docs/DemoStatra_사이트_에이전트_작동점검_2026-06-24.md`

요약:

- Partner Discovery / B2B Matching 기능은 작동 확인
- `/partners/search` API는 정상 응답 확인
- Hermes AI 채팅 API `/agent/chat-stream`, `/agent/chat`은 404 오류 확인
- 인증 API `/auth/me`도 404 오류 확인
- 나머지 에이전트는 화면상 표시되지만 실제 업무 플로우는 추가 개발 필요

### 2.4 데이터 관련 보완사항

이번 PoC에서 가장 중요한 보완 주제는 “기능 버튼 수”가 아니라 **데이터 품질**이다.

보완 항목:

1. 참가기업 기본정보 정리
2. 제품/기술 키워드 구조화
3. 수출 가능 품목/타깃시장 정리
4. 인증/규제/품질 관련 정보 보완
5. 영문 기업명/제품명 정리
6. 홈페이지/브로셔 기반 설명 추출
7. 바이어 후보 추천 근거 저장
8. 데이터 출처 및 신뢰도 표시
9. 누락 필드 표시
10. 담당자가 확인해야 할 항목 구분

### 2.6 최종 개선 방향

보고서의 개선 방향은 다음 순서로 제안한다.

1. 데이터 정리: KOAA SHOW 참가기업 데이터를 AX 프로필화
2. 매칭 고도화: 공개 웹 검색 + 내부 데이터 + 담당자 검증 결합
3. 담당자 화면: 후보 저장, 검토, 연락, 미팅 요청 기능
4. 에이전트 안정화: 채팅, Agent Hub, 미팅, 문서, 결제 기능 단계적 연결
5. K-Zotra 전환: 9월 브랜드/도메인 변경 시 기능 안정화와 함께 전환
