# Antigravity 작업지시문: PoC 리포트 3페이지 문구 개선

## 1. 작업 대상

아래 HTML 브리핑 자료를 수정한다.

```text
D:/demostatra-project/KOAA_SHOW_PoC_Report/ain_global_ax_data_briefing/index.html
```

이번 작업은 **PoC 리포트 3페이지**에 있는 아래 문구를 더 설득력 있게 바꾸는 것이다.

현재 문구:

```text
3. 사용자의 변화하는 수요를 유연하게 반영한다
```

이 표현은 의미는 맞지만 다소 밋밋하므로, DemoStatra가 단순 기업 검색기가 아니라 **수요를 읽는 B2B 매칭 플랫폼**이라는 느낌이 나도록 수정한다.

---

## 2. 최종 교체 문구

현재 문구를 아래 문구로 교체한다.

```text
3. 업체를 찾는 매칭에서, 수요를 읽는 매칭으로 전환한다
```

---

## 3. 하단 설명 문구

해당 항목 아래 설명문이 있다면 아래 문구로 교체하거나 추가한다.

```text
정적인 기업정보에만 의존하지 않고, 품목·국가·시장 트렌드와 바이어의 현재 관심 변화를 함께 반영해 거래 가능성이 높은 방향으로 추천 기준을 조정합니다.
```

---

## 4. 표현 의도

이 문구의 의도는 다음이다.

기존 표현:

```text
사용자의 변화하는 수요를 유연하게 반영한다
```

문제점:

- 의미는 맞지만 일반적이고 힘이 약하다.
- DemoStatra의 차별성이 잘 드러나지 않는다.
- 단순 기능 설명처럼 보인다.

수정 후 표현:

```text
업체를 찾는 매칭에서, 수요를 읽는 매칭으로 전환한다
```

장점:

- 기존 B2B 플랫폼의 단순 업체 검색과 DemoStatra의 방향이 대비된다.
- “수요를 읽는 매칭”이라는 표현이 플랫폼의 지능화 방향을 보여준다.
- 아인글로벌 담당자가 직관적으로 이해하기 쉽다.
- 이후 AX DB 구축, 동적 수요 시그널, 실거래 기반 추천 가설과 자연스럽게 연결된다.

---

## 5. 문맥 연결 주의

이 문구는 다음 개념들과 자연스럽게 연결되어야 한다.

```text
- AX DB 구축
- 정적인 기업정보의 한계
- 바이어의 현재 관심 변화
- 품목·국가·시장 트렌드 반영
- 단순 유사도 매칭의 한계
- 실거래 기반 군집 추천 가설
```

따라서 주변 문장에 “단순 검색”, “정적 기업정보”, “동적 수요”, “추천 기준 조정” 같은 표현이 있다면 새 문구와 어색하지 않게 맞춘다.

---

## 6. 대체 후보 문구, 필요 시 참고만 할 것

최종 선택 문구는 위의 문구이지만, 레이아웃상 너무 길거나 줄바꿈이 어색하면 아래 후보 중 하나를 사용할 수 있다.

### 후보 A

```text
3. 정적인 기업정보를 넘어, 동적인 수요 시그널을 반영한다
```

설명:

```text
기업의 고정된 등록 정보에만 의존하지 않고, 검색·문의·시장 트렌드·전시회 상담 이력 등 현재 수요를 보여주는 동적 시그널을 반영해 더 정밀한 매칭을 수행합니다.
```

### 후보 B

```text
3. 고정된 매칭 기준을 넘어, 살아 움직이는 수요를 추적한다
```

설명:

```text
품목·국가·시장 트렌드의 미세한 변화를 포착해 추천 기준을 고정하지 않고, 바이어의 현재 관심과 수요 변화에 맞춰 매칭 가중치를 유연하게 조정합니다.
```

단, 특별한 문제가 없으면 최종 문구를 그대로 사용한다.

---

## 7. 금지 표현

아래 표현은 쓰지 않는다.

```text
실시간으로 완벽히 추적한다
수요 변화를 자동으로 정확히 예측한다
거래 가능성을 보장한다
거래성사율을 입증했다
바이어 수요를 즉시 파악한다
```

이유:

- 현재 PoC 단계에서는 실거래 데이터와 정답 데이터가 충분하지 않다.
- “실시간”, “완벽히”, “보장”, “입증” 같은 표현은 과장으로 보일 수 있다.

---

## 8. 권장 표현 톤

아래 정도의 표현 톤을 유지한다.

```text
반영한다
조정한다
전환한다
추적한다
포착한다
검증한다
고도화한다
```

단, “검증 완료”, “입증”은 사용하지 않는다.

2. 새 문구가 너무 길어 슬라이드 레이아웃을 깨지 않는가?
3. 하단 설명이 새 제목과 자연스럽게 연결되는가?
