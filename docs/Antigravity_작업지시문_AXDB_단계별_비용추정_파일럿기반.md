# Antigravity 작업지시문: AX DB 구축 비용을 파일럿 기반 단계별 추정 방식으로 수정

## 1. 작업 대상

아래 HTML 발표자료를 수정한다.

```text
D:/demostatra-project/KOAA_SHOW_PoC_Report/ain_global_ax_data_briefing/index.html
```

이번 작업은 AX DB 구축 소요시간·비용 표현을 수정하는 것이다.

중요: 현재 시점에서 9만 개 또는 10만 개 전체 AX DB 구축 비용을 단정적으로 제시하지 않는다.

---

## 2. 수정 배경

기존에는 전체 9만 개 업체를 대상으로 웹사이트 공개정보를 수집하고 AX 프로필 초안을 만들 경우의 대략적 API·토큰·운영비를 추정할 수 있었다.

하지만 발표자료에서는 다음 이유로 전체 비용을 지금 단정적으로 제시하지 않는 것이 안전하다.

1. 업체별 웹사이트 품질 차이가 크다.
2. 웹사이트 접속 실패, 다국어, PDF 브로셔, 이미지/OCR, 인증자료 유무에 따라 비용 편차가 크다.
3. 품목·인증·수요·거래조건·바이어 유형 등 AX 필드별 자동 추출 가능률이 다르다.
4. 국내업체와 해외 바이어의 데이터 구조가 다르다.
5. 실제 수입 이력, 담당자 연락처, 거래조건은 외부 DB나 담당자 검수가 필요할 수 있다.
6. 따라서 전체 구축 비용은 먼저 샘플 AX 프로필을 만들어 본 뒤 실측값을 근거로 산정하는 것이 신뢰도가 높다.

---

## 3. 핵심 메시지

발표자료에는 아래 메시지를 중심으로 넣는다.

```text
전체 AX DB 구축 비용은 현재 단정하지 않고, 먼저 국내업체 1,000개사와 해외 바이어 1,000개사, 총 2,000개사의 AX 프로필을 파일럿으로 구축한 뒤 실제 소요시간·비용·자동 추출 성공률을 측정하여 단계별 확장 비용을 산정합니다.
```

더 짧은 핵심 문장:

```text
2,000개사 파일럿 실측값을 기준으로 1만 → 3만 → 6만 → 10만 개사 AX DB 구축비용을 단계별로 산정합니다.
```

## 4. 기존 비용 단정 표현 제거

만약 기존 슬라이드나 텍스트에 아래와 같은 표현이 있다면 삭제하거나 완화한다.

삭제/완화 대상:

```text
90,000개 전체 구축 비용은 200만~800만 원 수준
1,000개 샘플은 10만~30만 원
10,000개는 50만~150만 원
2~4주면 전체 AX DB 구축 가능
1천만 원 이하로 전체 구축 가능
```

이런 구체 비용은 현재 발표자료에 넣지 않는다.

대신 아래처럼 바꾼다.

```text
전체 비용은 2,000개사 파일럿 구축 후 실측값을 기준으로 산정
단계별 확장 과정에서 소요시간·비용·품질을 재측정하고 보정
```

## 5. 새 슬라이드 추가 또는 기존 슬라이드 보완

AX DB 구축 방식 설명 슬라이드 뒤에 새 슬라이드를 1장 추가하거나, 기존 AX DB 구축 로드맵 슬라이드에 아래 내용을 추가한다.

추천 제목:

```text
AX DB 구축비용은 파일럿 실측 후 단계별로 산정합니다
```

추천 부제:

```text
국내업체 1,000개사와 해외 바이어 1,000개사의 AX 프로필을 먼저 구축하고, 실제 소요시간·비용·품질지표를 기준으로 전체 확장 계획을 조정합니다.
```

## 6. 슬라이드 본문 구조

슬라이드는 아래 3단 구조로 만든다.

### 1단계: 2,000개사 파일럿

제목:

```text
1단계: 2,000개사 파일럿 AX 프로필 구축
```

본문:

```text
국내업체 1,000개사와 해외 바이어 1,000개사를 선정하여 웹사이트 공개정보 기반 AX 프로필 초안을 생성합니다. 이 단계에서 자동 수집 가능 항목, 검수 필요 항목, 외부 데이터 보강 필요 항목을 구분합니다.
```

측정 항목:

```text
- 업체당 평균 수집 페이지 수
- 웹사이트 접속 성공률
- 품목 추출 성공률
- 인증/표준 정보 추출 가능률
- 바이어 유형 분류 가능률
- 거래조건·수요정보 확인 가능률
- AI 토큰 사용량
- 수집 API 사용량
- 담당자 검수 소요시간
```

---

### 2단계: 단계별 확장 비용 산정

제목:

```text
2단계: 실측값 기반 단계별 비용 산정
```

본문:

```text
2,000개사 파일럿 결과를 기준으로 1만 개사, 3만 개사, 6만 개사, 10만 개사 확장 시 필요한 소요시간과 비용을 추정합니다.
```

확장 단계:

```text
2,000개사 파일럿 → 10,000개사 → 30,000개사 → 60,000개사 → 100,000개사
```

---

### 3단계: 단계별 보정 및 품질 개선

제목:

```text
3단계: 단계별 비용·품질 파인튜닝
```

본문:

```text
각 확장 단계마다 실제 수집 성공률, 토큰 사용량, 검수시간, 데이터 품질을 다시 측정하여 다음 단계의 비용과 기간을 보정합니다. 이를 통해 과소·과대 추정을 줄이고, 운영 가능한 AX DB 구축 모델을 확립합니다.
```

## 7. 추천 도식

슬라이드 중앙에 아래와 같은 단계형 화살표 도식을 넣는다.

```text
2,000개사 파일럿
국내 1,000 + 해외 1,000
        ↓ 실측
10,000개사 확장
        ↓ 보정
30,000개사 확장
        ↓ 보정
60,000개사 확장
        ↓ 보정
100,000개사 AX DB 초안 구축
```

각 단계 아래에는 짧게 표시한다.

```text
실측 → 추정 → 확장 → 재측정 → 보정
```

## 8. 단계별 표 추가

아래 표를 넣는다. 숫자 비용은 현재 넣지 않는다.

| 단계 | 대상 규모 | 주요 목적 | 산정 방식 |
|---|---:|---|---|
| 파일럿 | 2,000개사 | AX 필드 추출 가능성 실측 | 실제 API·토큰·검수시간 측정 |
| 1차 확장 | 10,000개사 | 국가·품목별 품질 편차 확인 | 파일럿 단가 기반 추정 후 보정 |
| 2차 확장 | 30,000개사 | 해외 바이어 DB 중심 확장 | 수집 실패율·검수시간 재측정 |
| 3차 확장 | 60,000개사 | 국내업체 DB 중심 확장 | 자동화율과 검수범위 조정 |
| 전체 확장 | 100,000개사 | AI 매칭용 AX DB 초안 구축 | 단계별 실측값 누적 기반 산정 |

아래 문장을 슬라이드 또는 발표자 설명에 넣는다.

```text
현재 단계에서 전체 구축비용을 단정하기보다, 먼저 2,000개사 파일럿을 통해 업체당 실제 수집 페이지 수, API 사용량, AI 토큰 사용량, 검수 소요시간, 데이터 품질을 측정한 뒤 단계별 확장 비용을 산정하는 방식이 현실적입니다.
```

또는 짧게:

```text

```

## 10. 발표자가 말할 수 있는 설명 문안

발표자가 아래 취지로 설명할 수 있도록 자료를 구성한다.

```text
당초 6월에는 국내업체 1,000개사와 해외 바이어 1,000개사의 AX 프로필을 먼저 만들어보려 했습니다. 이 작업이 진행되면 업체별 웹사이트에서 실제로 어떤 정보가 자동 수집되는지, 어떤 항목은 검수가 필요한지, API와 AI 토큰이 얼마나 쓰이는지를 실측할 수 있습니다.

따라서 현재 시점에서 9만 개 또는 10만 개 전체 구축비용을 단정하지 않고, 먼저 2,000개사 파일럿을 수행한 뒤 그 결과를 기준으로 1만 개사, 3만 개사, 6만 개사, 10만 개사 확장 비용을 단계별로 산정하겠습니다.

각 단계마다 실제 소요시간과 비용, 데이터 품질을 다시 측정하여 다음 단계의 추정치를 보정하면 과소·과대 추정을 줄일 수 있습니다.
```

## 13. 기존 2~3개월 PoC 로드맵과 연결

2~3개월 연장 PoC의 첫 번째 실행 과제로 아래 내용을 넣는다.

```text
국내업체 1,000개사 + 해외 바이어 1,000개사 AX 프로필 파일럿 구축
```

두 번째 실행 과제로 아래 내용을 넣는다.

```text
파일럿 결과 기반 1만·3만·6만·10만 개사 확장 비용 산정
```

세 번째 실행 과제로 아래 내용을 넣는다.

```text
단계별 수집 성공률, API/토큰 사용량, 검수시간, 매칭 품질지표를 보정하며 확장 로드맵 확정
```
