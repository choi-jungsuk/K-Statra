# Antigravity 작업지시문: AX 프로필 자동수집 시연 및 과장 방지 문구 추가

## 1. 작업 대상

아래 HTML 브리핑 자료를 수정한다.

```text
D:/demostatra-project/KOAA_SHOW_PoC_Report/ain_global_ax_data_briefing/index.html
```

이번 작업은 기존 브리핑 자료에 **AX DB 구축 방식의 현실적 설명과 시연용 페이지**를 보완하는 것이다.

특히 사용자가 우려한 부분은 다음이다.

> “품목·인증·수요·타겟국가·거래조건·바이어 유형 등의 필드를 표준화한 AX 프로필 구조로 전환할 필요가 있다”는 말이 너무 쉽게 들리거나, 자동으로 완성되는 것처럼 과장되어 보이면 안 된다.

따라서 자료에는 **자동 수집 가능 항목, AI 추정 가능 항목, 추가 검증 필요 항목**을 명확히 구분해서 넣는다.


## 5. 신규 슬라이드 핵심 구성

슬라이드는 3단계 흐름으로 구성한다.

```text
1단계: DemoStatra 추천 후보 도출
2단계: 공개 웹사이트 기반 AX 프로필 초안 생성
3단계: 담당자 검수 및 외부 DB 보강
```

### 1단계 카드

제목:

```text
1. 추천 후보 도출
```

내용:

```text
DemoStatra에서 자동차부품 바이어 후보를 검색하고, 추천된 기업 중 하나를 선택합니다.
```

예시:

```text
예: 미국 자동차부품 관련 바이어 후보 검색 → Nordson 등 후보 기업 확인
```

단, 특정 회사명을 넣는 것이 부담스럽다면 아래처럼 일반화한다.

```text
예: 미국 자동차부품 관련 바이어 후보 검색 → 후보 기업 웹사이트 확인
```

---

### 2단계 카드

제목:

```text
2. AX 프로필 초안 생성
```

내용:

```text
기업 웹사이트, 제품 페이지, 인증·표준 페이지, 글로벌 네트워크 정보를 수집해 품목·산업분야·시장·바이어 유형 등 AX 프로필 필드를 초안화합니다.
```

---

### 3단계 카드

제목:

```text
3. 검수 및 보강
```

내용:

```text
AI가 추정한 항목은 담당자가 검수하고, 실제 수입 이력·담당자 연락처·거래조건은 Kompass, TradeAtlas, 전시회 참가정보, 상담 이력 등으로 보완합니다.
```

## 6. 수집 가능/검수 필요/추가 데이터 필요 구분표

신규 슬라이드 하단 또는 오른쪽에 아래 표를 넣는다.

| 구분 | 항목 | 설명 |
|---|---|---|
| 자동 수집 가능 | 회사명, 국가, 웹사이트, 주요 품목, 산업 분야, 제품 카테고리, 글로벌 지사/시장, 공개 인증/표준, 문의 채널 | 웹사이트와 공개자료에서 비교적 수집 가능 |
| AI 추정 가능 / 검수 필요 | 바이어 유형, 수요 가능성, 한국 기업과의 적합성, 자동차부품 관련성 | AI가 초안 분류 후 담당자 검수 필요 |
| 추가 데이터 필요 | 실제 수입 이력, HS Code별 거래 기록, 구매 담당자 직통 이메일, 거래조건, MOQ, 결제조건, 최근 구매 시점, 거래성사 가능성 | 외부 DB, 전시회 상담, 실제 거래 데이터로 보완 필요 |

표가 너무 길면 아래처럼 짧게 요약한다.

```text
자동 수집 가능: 회사명·국가·웹사이트·품목·산업분야·공개 인증
검수 필요: 바이어 유형·수요 가능성·자동차부품 관련성
추가 데이터 필요: 실제 수입 이력·담당자 연락처·거래조건·HS Code 거래기록
```

## 7. AX 프로필 초안 예시 박스

공간이 허용되면 신규 슬라이드에 예시 박스를 넣는다.

### 예시 제목

```text
AX 프로필 초안 예시
```

### 예시 내용

```text
기업명: 후보 바이어 A
국가: 미국
웹사이트: 공개 웹사이트 확인
관련 품목: 자동차부품, 산업용 장비, 애프터마켓 부품 등
관련 산업: Automotive / Transportation / Industrial
바이어 유형: 제조공정 솔루션 기업 또는 부품 구매 가능 기업으로 추정
인증/표준: 공개 인증 페이지 확인 필요
수요 추정: 자동차부품 제조·정비·유통 관련 수요 가능성
거래조건: 공개 웹사이트만으로는 확인 제한, 별도 문의 필요
신뢰도: 중간 / 담당자 검수 필요
```

특정 회사명을 반드시 넣을 필요는 없다. 발표용으로 안전하게 하려면 “후보 바이어 A”로 표현한다.

## 9. 발표자가 말할 수 있는 설명 문안

가능하면 발표자 노트 또는 슬라이드 하단 설명에 아래 취지를 반영한다.

```text
지금 보시는 것은 AX DB가 자동으로 완성된다는 의미가 아닙니다. DemoStatra는 먼저 추천된 후보 기업의 웹사이트와 공개자료에서 품목, 산업분야, 인증, 글로벌 시장, 바이어 유형 등 AI가 읽을 수 있는 AX 프로필 초안을 생성합니다.

다만 실제 수입 이력, 거래조건, 담당자 연락처, 구매 가능성 같은 항목은 공개 웹사이트만으로는 한계가 있기 때문에, 담당자 검수와 Kompass·TradeAtlas 같은 외부 DB, 전시회 참가정보, 실제 상담 이력으로 보완해야 합니다.

즉, AX DB 구축은 자동 수집과 사람의 검수를 결합하는 단계적 과정입니다.
```

## 12. 디자인 지시

- 기존 브리핑 자료의 색상과 톤을 유지한다.
- 너무 기술자료처럼 복잡하게 만들지 않는다.
- 3단계 흐름은 아이콘과 화살표로 보여준다.
- “자동 수집 가능 / 검수 필요 / 추가 데이터 필요”는 색상으로 구분한다.

색상 예시:

```text
자동 수집 가능: 파란색 또는 초록색
검수 필요: 노란색 또는 주황색
추가 데이터 필요: 회색 또는 붉은색 경고톤
```

단, 붉은색을 너무 강하게 쓰지 말고 “보완 필요” 정도의 느낌으로 사용한다.
