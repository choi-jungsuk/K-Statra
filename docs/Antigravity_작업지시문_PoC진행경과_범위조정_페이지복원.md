# Antigravity 작업지시문: '그간의 진행경과와 범위 조정' 페이지 복원 및 재배치

## 1. 작업 대상

아래 HTML 브리핑 자료를 수정한다.

```text
D:/demostatra-project/KOAA_SHOW_PoC_Report/ain_global_ax_data_briefing/index.html
```

이번 작업은 기존 브리핑 자료에 있었던 **'그간의 진행경과와 범위 조정' 페이지를 복원**하고, 현재 2페이지인 **'PoC를 통해 확인한 핵심 과제: AX DB와 보안 운영 구조'** 앞에 배치하는 것이다.

## 2. 작업 배경

현재 브리핑 자료는 논리 흐름을 재정리하면서 다음 페이지가 빠진 것으로 보인다.

```text
그간의 진행경과와 범위 조정
```

이 페이지에는 아래 내용이 포함되어 있었다.

```text
- KOAA SHOW PoC의 당초 계획
- PoC 진행 중 범위 조정 사유
- 타겟국가 24개국
- 타겟품목군 19개 품목군
```

이 페이지는 매우 중요하다. 왜냐하면 바로 다음 페이지인 **'PoC를 통해 확인한 핵심 과제: AX DB와 보안 운영 구조'**가 왜 나오는지를 설명하는 배경 페이지이기 때문이다.

즉, 발표 흐름은 다음처럼 되어야 한다.

```text
01. 표지
02. 그간의 진행경과와 범위 조정
03. PoC를 통해 확인한 핵심 과제: AX DB와 보안 운영 구조
04. AI 시대 고객 정보 관리 고도화 방향
...
```

## 3. 최종 배치 위치

```text

'PoC를 통해 확인한 핵심 과제: AX DB와 보안 운영 구조' 앞
```

즉, 최종 초반 순서는 아래와 같다.

페이지가 1장 추가되므로 전체 페이지 수가 기존 13장에서 **14장**이 될 수 있다. 실제 슬라이드 개수에 맞춰 모든 하단 페이지 번호를 정리한다.

## 5. 슬라이드 부제

제목 아래 부제는 아래 문구를 사용한다.

```text
당초에는 보유 DB 기반의 B2B 매칭 고도화를 검증하려 했으나, 원천 데이터 직접 이전에 대한 보안 우려로 실제 DB 마이그레이션은 보류하고 AX 데이터 구조와 보안 운영 방식 검토 중심으로 범위를 조정했습니다.
```

표현 주의:

- “DB를 제공하지 않아 못했다”라고 쓰지 않는다.
- “아인글로벌 DB가 부족하다”라고 쓰지 않는다.
- “데이터 유출 우려”를 비판적으로 쓰지 않는다.
- “원천 데이터 직접 이전에 대한 보안 우려” 또는 “보안상 직접 이전은 보류”라고 쓴다.

## 10. 타겟국가 24개국 표시 방식

정확한 24개국 목록이 기존 HTML 또는 이전 자료에 남아 있다면, 반드시 기존 목록을 복원한다.

만약 기존 목록을 찾을 수 없다면, 임의로 새 국가를 만들어 넣지 말고 아래처럼 placeholder로 둔다.

```text
타겟국가 24개국: 기존 자료의 국가 목록 복원 필요
```

그리고 작업 완료 보고에 “기존 국가 목록 확인 필요”라고 표시한다.

절대 임의로 24개국을 새로 생성하지 않는다.

표시 예시:

```text
미국 · 독일 · 일본 · 중국 · 인도 · 베트남 · 멕시코 · 브라질 · 인도네시아 · 태국 · 튀르키예 · UAE · 사우디아라비아 · 폴란드 · 체코 · 헝가리 · 프랑스 · 이탈리아 · 스페인 · 영국 · 캐나다 · 호주 · 남아공 · 말레이시아
```

단, 위 목록은 예시일 뿐이다. 기존 자료에 실제 목록이 있으면 그 목록을 우선 사용한다.
