# DemoStatra 사이트 에이전트 작동 점검 메모

- 점검일시: 2026-06-24 14:08 KST 기준
- 대상 사이트: https://www.demostatra.com
- 관련 향후 변경: 2026년 9월 `www.k-zotra.com`으로 사이트명/도메인 변경 예정
- 작성 목적: 현재 공개 사이트의 6개 에이전트/매칭 기능 작동 상태를 간단히 정리하고, 6월 말 KOAA SHOW PoC 최종 결과보고서 및 이후 개선 작업의 기준 문서로 사용

---

## 1. 한 줄 결론

현재 DemoStatra는 **B2B 파트너 검색/매칭의 핵심 기능은 일부 작동**하지만, 화면에 보이는 6개 에이전트가 모두 실제 업무 플로우까지 완성되어 작동한다고 보기는 어렵다.

가장 안정적으로 확인된 기능은 **Partner Discovery / B2B Matching 검색 기능**이다. 반면 Hermes AI 채팅, Agent Hub 협업 API, 인증 API는 404 오류가 확인되어 보완이 필요하다.

---

## 2. 직접 확인한 정상 작동 항목

### 2.1 메인 검색 기능

테스트 질문:

> 한국 화장품을 미국 LA에 수출하고 싶어. 좋은 바이어를 찾아줘.

확인 결과:

- 검색 입력 가능
- 백엔드 검색 API 응답 확인
- 검색 결과 표시 확인
- AI Insight 표시 확인
- 매칭 점수 표시 확인
- 결과 예시: BeauteTrade, Tradewheel, Yelp, Reddit, ASD Market Week 등 웹 기반 후보

백엔드 호출 결과:

```text
GET /partners/search?... 
HTTP/1.1 200 OK
```

판단:

> B2B Matching / Partner Discovery 기능은 현재 DemoStatra의 가장 강한 작동 기능이다.

단, 결과는 아직 “검증 완료된 자체 기업 DB”라기보다는 **웹 검색 + 공개자료 기반 후보 추천** 성격이 강하다.

## 3. 오류 또는 미완성으로 확인된 항목

### 3.1 Hermes AI 채팅 API 오류

오른쪽 하단 `Chat with Hermes AI` 채팅창에서 질문을 보냈으나 AI 답변이 정상 표시되지 않았다.

확인된 API 오류:

```text
GET /agent/chat-stream
HTTP/1.1 404 Not Found

POST /agent/chat
HTTP/1.1 404 Not Found
```

판단:

> 프론트엔드는 Hermes AI 채팅 API를 호출하고 있으나, 현재 백엔드에는 해당 라우트가 없거나 배포되지 않은 상태로 보인다.

우선순위: **높음**

---

### 3.2 인증 API 오류

사이트 접속 시 프론트엔드가 다음 API를 호출하는 것이 확인되었다.

```text
GET /auth/me
HTTP/1.1 404 Not Found
```

판단:

> 로그인 상태 확인 API가 프론트엔드와 백엔드 사이에서 맞지 않는다. 향후 로그인, My Partners, 결제, 저장 기능에 영향을 줄 수 있다.

우선순위: **높음**

---

### 3.3 Agent Hub 협업 보드

Agent Hub 화면은 다음 요소를 표시한다.

- Antigravity IDE
- Hermes Host
- Claude Managed
- Azure AI Agent
- Collaborative Search
- Developer Console
- Real-time Streaming & Verified Data

빠른 버튼 `K-Beauty Export Partner Match` 클릭 시 화면 로그는 움직였다.

예시 로그:

```text
[Antigravity IDE] Received User Query...
[Claude Managed Agent] Triggered tool calling: "search_partners"
```

하지만 동시에 `/agent/chat-stream`, `/agent/chat` API 오류가 확인되었다.

판단:

> Agent Hub는 시각적으로는 멋진 에이전트 협업 화면이지만, 실제 백엔드 에이전트 연결은 아직 완전하지 않은 상태로 보인다.

9월 `www.k-zotra.com`으로 변경할 때는 단순히 로고와 이름만 바꾸면 안 된다. 아래를 같이 변경해야 한다.

2. Railway 프론트엔드 커스텀 도메인 연결
3. 백엔드 CORS 설정에 새 도메인 추가
4. 환경변수 확인
   - `FRONTEND_URL`
   - `CORS_ORIGINS`
   - `APP_URL`
   - OAuth callback URL이 있다면 함께 변경
5. 사이트 텍스트 변경
   - DemoStatra → K-Zotra
   - Hermes AI 문구
   - Footer 저작권
   - About Us
   - 이메일/알림 템플릿
6. SEO 변경
   - title
   - description
   - OpenGraph
   - sitemap.xml
   - robots.txt

## 7. 현재 판단

현재 사이트는 완전히 미작동 상태가 아니다. 오히려 **B2B 검색/매칭 데모는 의미 있게 작동**한다.

다만 6월 말 KOAA SHOW PoC 최종보고서에서는 다음처럼 표현하는 것이 적절하다.

> DemoStatra는 Partner Discovery / B2B Matching 중심 기능은 작동 중이며, AX 데이터 수집, 미팅, 결제, 전문가 상담, 무역문서 에이전트는 화면상 구성되어 있으나 실제 백엔드 연결과 업무 플로우는 단계적 보완이 필요하다.
