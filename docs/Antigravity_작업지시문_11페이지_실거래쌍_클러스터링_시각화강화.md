## 4. 시각화 구조

현재 화면의 “신규 업체 A → 패턴 매핑 → 거래 패턴 군집” 흐름은 유지하되, 오른쪽 군집 영역을 더 명확하게 클러스터링 그림으로 바꾼다.

권장 구조:

```text
[왼쪽] 신규 KOAA 참가기업 A
        ↓
[가운데] AX 프로필 + 거래 패턴 매핑
        ↓
[오른쪽] 실거래쌍 기반 클러스터 3개
        ↓
[하단/오른쪽] 적격 바이어 후보 추천 → KOAA SHOW 초청/상담 유도
```

---

## 5. 오른쪽 군집 그림 상세 지시

오른쪽 영역에는 2~3개의 반투명 원형 군집을 배치한다. 각 군집 안에는 작은 점들을 여러 개 찍어서 일반적인 클러스터링 이미지를 연상시키게 한다.

각 점의 의미:

```text
작은 점 1개 = 실제 거래가 성사된 수출업체·수입업체 쌍 1개 또는 유사 거래 패턴 1개
```

시각 요소:

```text
- 연한 초록색 또는 민트색 반투명 원 3개
- 각 원 안에 작은 점 20~40개 정도
- 일부 점은 다른 색으로 강조: 추천 후보 바이어
- 신규 업체 A에서 가장 가까운 군집으로 점선 화살표 연결
- 선택된 군집 주변에 굵은 테두리 또는 강조 효과
```

권장 군집 라벨:

```text
Cluster 1: 애프터마켓 부품 바이어군
Cluster 2: 전장·미래차 부품 바이어군
Cluster 3: 특장·상용차 부품 바이어군
```

단, 실제 품목이 확정된 것은 아니므로 너무 단정하지 말고 “예시” 성격으로 표현한다.

표기 예:

```text
예시 군집 A: 애프터마켓 부품 거래 패턴
예시 군집 B: 전장·미래차 부품 거래 패턴
예시 군집 C: 특장·상용차 부품 거래 패턴
```

## 6. 수출업체·수입업체 쌍 표현

군집 안의 일부 대표 점에는 작은 라벨을 붙인다.

예시:

```text
수출 K1 ↔ 바이어 U1
수출 K2 ↔ 바이어 M1
수출 K3 ↔ 바이어 V1
```

주의:

- 실제 회사명을 쓰지 않는다.
- K1, K2, U1, M1 같은 익명 라벨을 사용한다.
- “성공 거래쌍” 또는 “실거래쌍”이라고 표현한다.

추천 라벨:

```text
실거래쌍
Transaction Pair
```

## 7. 적격 바이어 추천 및 KOAA SHOW 유도 흐름 추가

군집 그림 오른쪽 또는 하단에 최종 출력 영역을 추가한다.

권장 문구:

```text
적격 바이어 후보 추천
→ KOAA SHOW 초청
→ 사전 상담 매칭
```

또는:

```text
거래 패턴이 가까운 바이어를 선별해 KOAA SHOW 참가·상담으로 연결
```

이 흐름이 반드시 보여야 한다.

즉, 단순히 “군집화”로 끝나지 말고, 최종 목적이 아래임을 보여준다.

```text
적격 비즈니스 파트너 추천
KOAA SHOW 참석 유도
상담 성사 가능성 제고
```

단, “상담 성사 보장”, “거래 성사 보장”은 쓰지 않는다.

## 8. 하단 설명 문구 교체/보완

현재 하단 문구가 아래와 유사하다.

```text
단순 프로필 유사도가 아닌, 실제 거래가 성사된 쌍(Transaction Pairs)의 공통 거래 패턴 군집을 기준으로 매칭하여, 협력 및 성사 가능성이 실질적으로 높은 바이어를 식별합니다.
```

이를 아래 문구로 다듬는다.

추천 하단 문구:

```text
단순 프로필 유사도만 보지 않고, 실제 거래가 성사된 수출업체·수입업체 쌍의 공통 패턴을 군집화합니다. 신규 참가기업은 가장 가까운 거래 패턴 군집에 매핑되고, 그 안에서 KOAA SHOW 상담으로 연결할 적격 바이어 후보를 선별합니다.
```

좀 더 짧은 버전:

```text
실거래가 성사된 수출·수입 업체쌍을 거래 패턴별로 군집화하고, 신규 참가기업과 가까운 군집에서 KOAA SHOW 상담으로 연결할 적격 바이어 후보를 추천합니다.
```

공간이 부족하면 짧은 버전을 사용한다.

## 9. 슬라이드 내 3단 논리 박스 추가

시각화 아래 또는 옆에 작은 3단 논리 박스를 넣는다.

```text
① 실거래쌍 학습
수출업체와 수입업체 간 실제 거래 사례를 거래 패턴 단위로 구조화

② 거래 패턴 군집화
품목, 국가, 기업유형, 인증, 수요 특성이 유사한 거래쌍을 클러스터로 묶음

③ 적격 바이어 추천

```

이 3단 박스가 있으면 군집화 그림이 단순 장식이 아니라 실제 논리로 읽힌다.


```text
- 별표 아이콘
- 굵은 테두리 점
- 다른 색 점
- “추천 후보” 작은 라벨
```

## 11. 기술적으로 구현하는 방법

HTML/CSS에서 이미지 파일을 새로 만들 필요 없이, 가능하면 CSS div/svg로 그린다.

추천 구현 방식:

```text
- SVG를 사용해 좌표축 없는 클러스터링 산점도 표현
- <circle> 요소로 반투명 군집 원 생성
- 작은 <circle> 요소 여러 개로 점 표현
- <path> 또는 <line>으로 화살표 표시
- text 요소로 군집 라벨 표시
```

주의:

- 외부 이미지 링크를 사용하지 않는다.
- 발표자료가 오프라인에서도 열릴 수 있도록 HTML 내부 SVG/CSS로 구현한다.
- 레이아웃이 깨지지 않도록 1122px 슬라이드 폭 안에 맞춘다.

## 13. 발표자가 말할 수 있는 설명 문안

슬라이드 설명 흐름은 아래와 같다.

```text
기존 B2B 매칭은 보통 업체 프로필이 얼마나 비슷한지를 기준으로 추천합니다. 하지만 너무 유사한 업체는 오히려 경쟁사일 수 있고, 실제 거래 가능성이 높다고 단정하기 어렵습니다.

DemoStatra의 차별화 가설은 실제 거래가 성사된 수출업체와 수입업체 쌍을 기준으로 공통 거래 패턴을 찾는 것입니다. 거래가 일어난 업체쌍들을 품목, 국가, 기업유형, 인증, 수요 특성에 따라 군집화하면, 신규 참가기업이 어느 거래 패턴 군집에 가까운지 볼 수 있습니다.

그다음 해당 군집 안에서 KOAA SHOW 상담으로 연결할 적격 바이어 후보를 선별합니다. 현재 단계에서는 완성된 모델이 아니라, 2~3개월 연장 PoC에서 검증할 차별화 가설입니다.
```
