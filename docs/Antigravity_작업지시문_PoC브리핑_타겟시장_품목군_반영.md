# Antigravity 작업지시문: PoC 브리핑 자료에 대륙별 타겟시장과 타겟 품목군 반영

## 1. 작업 대상

아래 HTML 브리핑 자료를 수정한다.

```text
D:/demostatra-project/KOAA_SHOW_PoC_Report/ain_global_ax_data_briefing/index.html
```

이번 작업은 PoC 브리핑 자료에 **대륙별 타겟시장**과 **타겟 아이템/품목군**을 명확히 반영하는 것이다.

대표 목적은 다음과 같다.

```text
아인글로벌이 보유한 실제 검토 범위, 즉 타겟시장과 타겟 품목군을 발표자료에 구체적으로 보여줌으로써, 우리가 PoC 대상과 사업 맥락을 충분히 숙지하고 있다는 신뢰를 주는 것.
```

## 2. 삽입 위치

우선 삽입 대상은 이전 작업지시문에서 복원하도록 한 아래 페이지다.

```text
그간의 진행경과와 범위 조정
```

이 페이지는 표지 다음, 아래 페이지 앞에 배치되어야 한다.

```text
PoC를 통해 확인한 핵심 과제: AX DB와 보안 운영 구조
```

즉, 초반 흐름은 아래와 같아야 한다.

```text
01. 표지
02. 그간의 진행경과와 범위 조정
03. PoC를 통해 확인한 핵심 과제: AX DB와 보안 운영 구조
```

`그간의 진행경과와 범위 조정` 페이지 안에 아래 정보를 넣는다.

```text
- 대륙별 타겟시장
- 타겟 아이템/품목군
```

만약 한 장에 너무 복잡하면 아래 중 하나로 처리한다.

1. 2페이지 하단에 요약형으로 넣고, 세부 목록은 별도 보조 박스 또는 작은 글씨로 배치
2. `그간의 진행경과와 범위 조정` 다음에 `검토 대상: 대륙별 타겟시장과 품목군` 슬라이드를 1장 추가

추천은 **2페이지 안에 요약형으로 넣되, 화면이 복잡하면 별도 슬라이드 1장 추가**이다.


주의:

- 위 목록 기준으로 실제 기재된 국가는 23개국이다.
- 기존 자료에 “24개국”이라고 되어 있다면, 자료상 표현은 다음처럼 처리한다.

```text
타겟시장: 대륙별 주요 타겟국가
```

또는

```text
타겟국가: 23개국 기재 / 기존 24개국 목록 확인 필요
```

- 절대 임의로 누락된 1개 국가를 만들어 넣지 않는다.
- 만약 기존 HTML 또는 원본 자료에서 24번째 국가를 확인할 수 있으면, 그 국가를 추가하고 `24개국`으로 표기한다.
- 확인되지 않으면 작업 완료 보고에 “기존 24개국 중 1개국 확인 필요”라고 남긴다.

## 7. 품목군을 너무 길게 보이지 않게 하는 표시 방식

19개 품목군을 한 줄씩 길게 나열하면 슬라이드가 복잡해질 수 있다. 가능하면 아래처럼 4개 묶음으로 정리한다.

### 묶음 A. 차체·샤시·시트·브라켓

```text
시트 / 차량용 샤시·시트프레임 / 자동차 브라켓 생산 / 차체·샤시·브라켓 생산 / 자동차 차체용 부품·알루미늄 다이캐스팅 제품
```

### 묶음 B. 금형·범퍼·기계부품

```text
자동차 금형 / 자동차 및 가전 금형 / 자동차 범퍼·크래쉬 패드 / 조향시스템·펌프·밸브 / 기어·기어박스·기어펌프
```

### 묶음 C. 특수·특장·복지차량

```text
특수 차량 / 특장차량 / 특장·복지차량 제조 및 부품제조
```

### 묶음 D. 미래차·전장·제조기술

```text
차량용 전장부품 / LIDAR 기반 자율주행 시스템 / 2차전지 설비 제조 / 탄소중립소재 제조 / 스마트팩토리 제조 업체 / 포터블 TV
```

주의:

- 위 묶음은 발표자료 가독성을 위한 분류다.
- 원본 19개 고유 품목군 목록도 가능하면 작은 글씨나 툴팁/보조 영역으로 유지한다.
- `포터블 TV`는 자동차부품과 다소 결이 다를 수 있으나, 사용자가 제공한 원본 목록이므로 삭제하지 않는다. 필요하면 `기타 전장/전자 응용` 또는 `미래차·전장·제조기술` 묶음에 포함한다.

## 9. 표현상 주의사항

아래 표현은 피한다.

```text
24개국 확정
19개 품목군 완전 검증
모든 품목군 매칭 가능
전 국가 실시간 바이어 확보
```

현재 제공 목록은 국가가 23개로 확인되므로, 24개국이라고 단정하지 않는다. 기존 자료에서 24번째 국가가 확인될 때만 `24개국`이라고 표기한다.

권장 표현:

```text
권역별 주요 타겟국가
타겟 아이템/품목군 19개
검토 대상 범위
AX DB 구축 및 매칭 고도화 검토 범위
```

## 10. 기존 '24개 타겟국가' 표현 처리

자료 어딘가에 기존처럼 아래 표현이 있으면:

```text
타겟국가 24개국
```

이번에 제공된 목록 기준으로는 23개국만 확인되므로 아래 중 하나로 처리한다.

### 24번째 국가 확인 가능 시

```text
타겟국가 24개국
```

그리고 실제 24개국 목록을 모두 표시한다.

### 24번째 국가 확인 불가 시

```text
권역별 주요 타겟국가
```

또는

```text
타겟국가: 제공 목록 기준 23개국 / 기존 24개국 목록 확인 필요
```

발표용으로는 화면에 `확인 필요`가 보이면 어색할 수 있으므로, 가능하면 제목은 아래처럼 한다.

```text
권역별 주요 타겟국가
```

작업 완료 보고에는 별도로:

```text
제공 목록은 23개국으로 확인되어, 기존 24개국 중 1개국 추가 확인 필요
```

라고 남긴다.

## 14. 작업 완료 후 보고 형식

작업 완료 후 아래 형식으로 보고한다.

```text
- 수정/추가한 슬라이드 제목
- 삽입 위치
- 대륙별 타겟시장 반영 여부
- 국가 수 확인 결과: 제공 목록 기준 23개국 / 기존 24번째 국가 확인 여부
- 타겟 품목군 반영 여부: 중복 제거 후 19개
- 품목군 묶음 표시 여부
- 페이지 번호 정리 여부
- 확인이 필요한 사항
```
