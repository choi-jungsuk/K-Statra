# 협력범위와 노하우 보호 메시지 전략

- 작성일: 2026-07-03
- 목적: 아인글로벌과 후속 협력을 이어가되, Gran Oso AI/DemoStatra의 핵심 영업무기와 운영 노하우를 과도하게 노출하지 않기 위한 커뮤니케이션 기준

---

## 1. 기본 원칙

```text
아인글로벌에는 “결과를 소유하고 검수할 수 있는 운영 구조”를 제공한다.
Gran Oso AI/DemoStatra의 “AX 데이터 생성 엔진과 운영 노하우 전체”는 제공하지 않는다.
```

---

## 2. 제공해도 되는 것

1. 아인글로벌 명의 DB 계정 개설 방법
2. 입력 데이터 제공 양식
3. AX Profile 산출물 예시
4. 2,000개사 AX Profile 초안 파일
5. 검수 체크리스트
6. 품질 등급표
7. 1만개사 확장 시 필요한 예산 항목 설명
8. 보안 운영 원칙

---

## 3. 조심해야 할 것

1. Hermes 설치·운영 방법 전체 공개
2. 프롬프트 원문 전체 공개
3. 자동 수집 스크립트 제공
4. 검색 실패 보정 노하우 공개
5. API 비용 최적화 방식 공개
6. 내부 점수 산정 로직 전체 공개
7. “아인글로벌도 직접 똑같이 만들 수 있다”는 인상을 주는 설명

---

## 4. 대표님이 말하면 좋은 표현

### DB 계정 관련

```text
DB는 아인글로벌 명의로 만드는 것이 맞습니다. 원천 데이터와 AX 산출물의 소유권과 보안 통제를 아인글로벌이 갖는 구조가 가장 안전합니다.
```

### 2,000개사 관련

```text
우선 국내 1,000개사와 해외 1,000개사를 대상으로 AX 프로필 초안을 만들어드리겠습니다. 이 파일럿을 통해 수집 성공률, 품질, 검수 난이도를 실측해보는 것이 좋겠습니다.
```

### 1만개사 확장 관련

```text
1만개사 이상은 처리량과 검수량이 커지기 때문에, 2,000개사 파일럿 결과를 보고 아인글로벌의 가용 예산 범위 안에서 단계적으로 확장하는 방식이 현실적입니다.
```

### Hermes/내부도구 질문이 나왔을 때

```text
내부적으로는 여러 AI 도구와 자동화 파이프라인을 조합해 처리합니다. 다만 담당자분들이 직접 운영하시기에는 복잡할 수 있어, 아인글로벌에는 입력 양식, DB 계정 운영, 결과 검수 방식 중심으로 매뉴얼을 드리는 것이 더 안전합니다.
```

---

## 5. 피해야 할 표현

```text
- Hermes 설치법을 다 알려드리겠습니다.
- 이건 누구나 쉽게 할 수 있습니다.
- 자동화 스크립트를 드리겠습니다.
- 앞으로는 직접 돌리시면 됩니다.
- 비용은 거의 안 듭니다.
- 1만개사도 그냥 해드리겠습니다.
```

---

## 6. 가장 좋은 포지셔닝

```text
아인글로벌은 DB와 시장 네트워크를 가진 기관,
Gran Oso AI/DemoStatra는 AX 데이터 구조화와 AI 매칭 엔진을 가진 실행 파트너.

양측의 역할을 분리해야 보안도 지키고, 후속 사업화도 가능하다.
```

## 7. 저녁 대학생 회식용 설명

```text
오늘 간담회에서 가장 반응이 좋았던 장면은 업체 웹사이트 하나만으로 AX Profile을 몇 분 안에 만들어낸 장면이었다.

이제 다음 단계는 아인글로벌이 가진 국내 1,000개사, 해외 1,000개사 디렉토리를 받아서 같은 방식으로 AX 프로필 초안을 만드는 것이다.

다만 우리가 가진 자동화 노하우를 모두 외부에 공개하는 것이 아니라, 아인글로벌에는 결과물과 검수 방식, DB 운영 구조를 제공하고, 우리는 AX 데이터 생성 파트너로서 역할을 가져가야 한다.
```
