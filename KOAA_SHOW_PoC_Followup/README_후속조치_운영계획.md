## 2. 후속작업 요약

### 작업 1. 아인글로벌 명의 DB 계정 개설 매뉴얼 제공

| 항목 | 내용 |
|---|---|
| 목표 | 아인글로벌 명의로 클라우드 DB 계정을 개설하고, 원천 데이터와 AX DB 산출물을 아인글로벌이 소유·통제하는 구조 마련 |
| 권장 방향 | 1차는 **MongoDB Atlas** 권장, 필요 시 PostgreSQL/Supabase 대안 제시 |
| 제공물 | 가입·설정·사용자 초대·데이터 보안 운영 매뉴얼 |
| 목표 일정 | 다음주 월요일 제공 |
| 표현 방식 | “기관 명의 DB 보관 + 승인된 작업자 접근 + 로그/권한 관리” |

### 작업 2. 국내 1,000개사 + 해외 1,000개사 AX 프로필 초안 생성

| 항목 | 내용 |
|---|---|
| 입력 | 업체명, 웹사이트 주소, 국가, 품목군, 비고 등이 포함된 2,000개사 디렉토리 |
| 출력 | Alltour Brake와 같은 AX Profile 초안 파일/표 형태 |
| 목표 일정 | 가능한 빠르게 착수, 7월말까지 1차 산출 |
| 범위 | 공개 웹사이트 기반 자동 수집·AI 구조화·초안 생성 |
| 제외 | 최종 검증, 수입 이력 확정, 담당자 연락처 보장, 거래 가능성 보장 |
| 후속 확장 | 1만개사부터는 예산 범위에 따라 별도 비용 협의 |

## 3. 전략적 줄타기 원칙

1. **아인글로벌이 DB를 소유·통제한다**는 메시지는 분명히 한다.
2. **Gran Oso AI/DemoStatra의 AX 생성 노하우 전체는 공개하지 않는다.**
3. 아인글로벌에는 “운영자 관점의 DB 계정 개설·데이터 제출·결과 확인 방법”까지만 제공한다.
4. Hermes 설치법·프롬프트·자동화 스크립트·대량처리 파이프라인 내부 구조는 외부 제공 범위에서 제외한다.
5. 2,000개사 초안은 후속 신뢰 형성용으로 제공하되, 1만개사 이상 확장은 예산 기반 유상 작업으로 자연스럽게 전환한다.
