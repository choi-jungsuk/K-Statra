# 아인글로벌 DB 계정개설 및 운영 매뉴얼 초안

- 작성일: 2026-07-03
- 목적: 아인글로벌 명의로 DB 계정을 개설하고, 원천 디렉토리와 AX 프로필 산출물을 안전하게 보관·관리하기 위한 안내
- 권장안: MongoDB Atlas 우선 / PostgreSQL 계열은 대안으로 제시

---

## 1. 결론: 1차 권장 DB는 MongoDB Atlas

### MongoDB Atlas를 우선 권장하는 이유

1. 업체별 AX 프로필은 회사마다 필드가 조금씩 달라질 수 있음
2. JSON 형태의 기업 프로필 저장에 적합함
3. Alltour Brake 같은 AX Profile 결과물을 거의 그대로 저장 가능함
4. 초기 운영자가 SQL에 익숙하지 않아도 비교적 이해하기 쉬움
5. 클라우드 기반으로 계정, 권한, 백업, 접근제어를 관리할 수 있음

### PostgreSQL/Supabase가 더 적합한 경우

1. 향후 정형 데이터 분석, 통계, 대시보드가 중요해질 때
2. 품목군, 국가, 상담이력, 담당자 정보를 엄격한 테이블 구조로 관리할 때
3. 개발팀이 SQL 기반 운영에 익숙할 때

### 이번 후속작업의 권장 판단

```text
2,000개사 AX 프로필 초안 생성 단계에서는 MongoDB Atlas를 우선 사용하고,
향후 서비스 운영·분석 단계에서 PostgreSQL/Supabase 병행 여부를 검토한다.
```

## 2. 아인글로벌이 직접 계정을 만들어야 하는 이유

```text
원천 업체 디렉토리와 AX DB 산출물은 아인글로벌의 사업 자산입니다.
따라서 DB 계정은 개발사나 외부 협력사가 아니라 아인글로벌 명의로 개설하고,
Gran Oso AI/DemoStatra는 승인된 작업 범위 안에서만 접근하는 구조가 안전합니다.
```

---

## 3. MongoDB Atlas 계정개설 절차 초안

> 실제 화면은 서비스 업데이트에 따라 조금 달라질 수 있으므로, 최종 매뉴얼 작성 시 캡처를 추가한다.

### Step 1. MongoDB Atlas 접속

```text
https://www.mongodb.com/atlas
```

### Step 2. 아인글로벌 업무용 이메일로 가입

권장:

```text
대표 개인 Gmail보다는 기관/업무용 이메일 사용
예: info@ainglobal.org 또는 담당자 회사 이메일
```

### Step 3. Organization / Project 생성

권장 이름:

```text
Organization: AIN Global
Project: DemoStatra AX DB Pilot
```

### Step 4. 무료 또는 최소 비용 클러스터 생성

초기 2,000개사 파일럿은 대용량이 아니므로 무료/소형 플랜으로 시작 가능하다. 단, 실제 운영 전에는 저장공간, 백업, 접근권한, 보안정책을 확인한다.

### Step 5. 데이터베이스 사용자 생성

역할 예시:

| 사용자 | 권한 | 용도 |
|---|---|---|
| ain-admin | 관리자 | 아인글로벌 내부 관리자 |
| demostatra-writer | 읽기/쓰기 제한 | AX 프로필 생성 작업용 |
| reviewer-readonly | 읽기 전용 | 담당자 검수용 |

### Step 6. 네트워크 접근 제한

초기에는 작업 편의상 허용 범위가 넓어질 수 있으나, 운영 단계에서는 접근 IP를 제한한다.

```text
원칙: 모든 IP 허용은 임시 사용만
운영: 승인된 사무실/작업자 IP 중심으로 제한
```

### Step 7. 컬렉션 구조 초안

```text
Database: demostatra_ax_pilot
Collections:
- raw_directory_companies
- ax_profiles_draft
- ax_profiles_reviewed
- processing_logs
- reviewer_feedback
```

## 6. 제공하지 않는 범위 / 내부 노하우 보호

아래 항목은 Gran Oso AI/DemoStatra의 내부 운영 노하우이므로 매뉴얼에 포함하지 않는다.

```text
- Hermes 내부 설치·운영 전체 절차
- 대량 수집 자동화 스크립트 원본
- 프롬프트 체인 전체
- API 키 및 모델 라우팅 전략
- 비용 최적화 로직
- 검색 실패 보정 로직
- 품질 점수 산정 내부 규칙 전체
```

대신 아인글로벌에는 다음까지만 제공한다.

```text
- 어떤 데이터를 준비하면 되는지
- 어디에 안전하게 올리면 되는지
- 결과물을 어떻게 확인하고 검수하면 되는지
- 어떤 항목이 검수 필요인지
```
