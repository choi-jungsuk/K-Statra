AIN Global × DemoStatra · DB Account Setup Manual

아인글로벌 DB 어카운트 개설
초보자 매뉴얼

엑셀 CRM에 익숙한 담당자를 위한 쉬운 안내서: 1안 MongoDB Atlas(우선 추천), 2안 PostgreSQL/Supabase

이 문서는 “개발자용 기술 문서”가 아니라, 아인글로벌 담당자가 직접 계정을 만들고 권한을 관리할 수 있도록 돕는 초보자용 매뉴얼입니다. 비밀번호, API Key, 접속 문자열은 문서나 카카오톡에 공유하지 말고 별도 보관하세요.

0. 먼저 이해하기: DB는 엑셀의 확장판입니다

엑셀

한 사람이 보기 쉽고, 표 형태로 정리하기 좋습니다. 하지만 여러 사람이 동시에 쓰거나, 대량 데이터를 안정적으로 관리하기에는 한계가 있습니다.

DB

웹사이트·AI 시스템·담당자 검수가 함께 쓰는 온라인 데이터 창고입니다. 접근권한, 백업, 로그, 보안 관리가 가능합니다.

AX DB

AI가 읽을 수 있도록 기업명, 웹사이트, 제품, 인증, 품목군, 상담 가능성, 검수 필요 항목을 구조화한 기업 프로필 저장소입니다.

1. 두 가지 선택안 요약

구분1안 MongoDB Atlas2안 PostgreSQL / Supabase
추천도우선 추천대안
초기 AX 프로필 저장매우 적합가능하나 설계가 조금 더 필요
엑셀 담당자 관점JSON 문서 저장소라 처음엔 낯설지만, AX Profile 형태와 잘 맞음표 형태라 엑셀과 유사하지만, 테이블 설계가 필요
사용 목적회사별 정보가 제각각인 AX 프로필 초안 저장정형화된 CRM, 상담이력, 통계, 대시보드
이번 PoC 후속작업국내 1천+해외 1천 AX Profile 초안 저장에 적합향후 운영/분석 단계에서 검토
권장 결론: 2,000개사 AX 프로필 초안 생성 단계에서는 MongoDB Atlas를 우선 사용하고, 향후 상담이력·통계·대시보드가 중요해지면 PostgreSQL/Supabase를 병행 검토합니다.

2. 계정 개설 전 준비물

  • 아인글로벌 업무용 이메일 주소
  • 휴대폰 또는 이메일 인증 가능 상태
  • 관리자 계정을 맡을 담당자 1명 지정
  • 작업자 계정을 받을 외부 협력자 목록 확인
  • 비밀번호를 저장할 안전한 내부 방법 결정
  • 가능하면 회사 카드 또는 결제 담당자 확인
중요: DB 계정은 아인글로벌 명의로 만듭니다. DemoStatra/Gran Oso AI는 승인된 작업자 계정으로만 접속하는 것이 보안과 소유권 측면에서 안전합니다.

3. 1안: MongoDB Atlas 계정 개설 — 우선 추천

MongoDB Atlas는 클라우드 기반 MongoDB 서비스입니다. AX Profile처럼 회사마다 정보 구조가 조금씩 다른 데이터를 저장하기에 적합합니다.

3-1. 가입하기

1
웹사이트 접속
https://www.mongodb.com/atlas 로 접속합니다.
2
Try Free 또는 Get Started 클릭
무료 시작 버튼을 누릅니다. 화면 문구는 시점에 따라 조금 달라질 수 있습니다.
3
아인글로벌 업무용 이메일로 가입
개인 이메일보다 회사 업무용 이메일 사용을 권장합니다.
4
이메일 인증
가입 메일함에서 MongoDB 인증 메일을 열고 Verify/Confirm 버튼을 누릅니다.

3-2. 조직과 프로젝트 만들기

5
Organization 이름
AIN Global 또는 Ain Global 로 입력합니다.
6
Project 이름
DemoStatra AX DB Pilot 로 입력합니다.

3-3. 무료 클러스터 만들기

7
Create Cluster / Build a Database 선택
처음에는 무료 또는 가장 작은 플랜을 선택합니다. 2,000개사 파일럿은 대용량이 아니므로 초기에는 소형으로 충분합니다.
8
Cloud Provider / Region 선택
AWS, Google Cloud, Azure 중 기본 추천값을 사용해도 됩니다. 지역은 가급적 서울 또는 일본/싱가포르 등 가까운 지역을 선택합니다. 무료 플랜에서 지역 선택이 제한되면 기본값으로 진행해도 됩니다.
9
Cluster 이름
demostatra-ax-pilot 로 입력합니다.

3-4. 접속 사용자 만들기

사용자명 예시권한용도
ain-admin관리자아인글로벌 내부 관리자
demostatra-writer읽기/쓰기AX 프로필 생성 작업용
reviewer-readonly읽기 전용담당자 검수용
10
Database Access 메뉴
좌측 메뉴에서 Database Access를 찾아 사용자 계정을 만듭니다.
11
비밀번호 생성
자동 생성 비밀번호를 사용하고, 안전한 내부 저장소에 보관합니다. 카카오톡/이메일 본문에 그대로 보내지 않습니다.

3-5. 네트워크 접근 설정

12
Network Access 메뉴
초기 설정 시 접속 허용 IP를 등록합니다. 급한 테스트에서는 임시로 넓게 허용할 수 있으나, 운영 단계에서는 승인된 IP만 허용합니다.
운영 원칙: 모든 IP 허용(0.0.0.0/0)은 테스트 때만 임시로 사용하고, 운영 단계에서는 제한하는 것이 안전합니다.

3-6. 데이터베이스 구조 초안

3-7. MongoDB Atlas에서 담당자가 할 일

  • 계정 개설
  • Organization/Project 생성
  • 관리자/작업자/검수자 계정 생성
  • 접속권한을 DemoStatra 작업자에게 승인
  • 결과 AX 프로필을 확인하고 검수 의견 전달

4. 2안: PostgreSQL / Supabase 계정 개설 — 대안

PostgreSQL은 오래된 표준 관계형 데이터베이스입니다. Supabase는 PostgreSQL을 쉽게 쓸 수 있게 해주는 클라우드 서비스입니다. 엑셀처럼 표 형태로 보는 데 익숙한 담당자에게는 Supabase의 Table Editor가 비교적 이해하기 쉽습니다.

4-1. 가입하기

1
Supabase 접속
https://supabase.com 로 접속합니다.
2
Start your project / Sign in 클릭
아인글로벌 업무용 이메일 또는 회사 관리 계정으로 가입합니다.
3
이메일 인증
메일함에서 인증을 완료합니다.

4-2. Organization / Project 만들기

4
Organization 이름
AIN Global 로 입력합니다.
5
New Project 만들기
프로젝트명은 DemoStatra AX DB Pilot 로 입력합니다.
6
Database Password 설정
매우 중요합니다. 안전한 비밀번호를 만들고 내부 보관소에 저장합니다. 분실하면 재설정이 번거로울 수 있습니다.
7
Region 선택
가능하면 한국과 가까운 지역을 선택합니다. 제한이 있으면 기본 추천값으로 진행합니다.

4-3. Supabase에서 표 만들기

Supabase는 좌측 메뉴의 Table Editor에서 엑셀처럼 표를 만들고 볼 수 있습니다.

테이블명용도
raw_directory_companies아인글로벌 제공 업체명/웹사이트 원본
ax_profiles_draftAI가 생성한 AX 프로필 초안
ax_profiles_reviewed담당자가 검수한 최종 후보
reviewer_feedback검수 의견 및 수정 요청

4-4. PostgreSQL/Supabase가 더 좋은 경우

  • 엑셀처럼 표 형태로 정리하고 싶을 때
  • 국가별, 품목군별, 상담상태별 통계를 자주 낼 때
  • 상담이력, 담당자, 후속조치 상태를 CRM처럼 관리할 때
  • 대시보드나 리포트를 만들 계획이 있을 때

7. 보안 주의사항

  • 비밀번호/API Key/Connection String은 문서에 적지 않는다.
  • 관리자 계정은 아인글로벌 내부 담당자가 보관한다.
  • 외부 협력자에게는 작업 범위에 맞는 제한 계정만 제공한다.
  • 작업 종료 후 외부 작업자 계정 권한을 회수하거나 비밀번호를 변경한다.
  • 원천 디렉토리와 AX 산출물은 아인글로벌 명의 DB 또는 승인 폴더에 보관한다.

지원 가능지원하지 않는 내부 노하우
