# 2,000개사 AX 프로필 생성 작업 운영계획

- 작성일: 2026-07-03
- 대상: 국내업체 1,000개사 + 해외업체 1,000개사
- 목표: Alltour Brake AX Profile과 같은 공개 웹사이트 기반 AX 프로필 초안을 생성해 아인글로벌 담당자에게 파일로 제공
- 목표 일정: 2026년 7월 말까지 1차 산출

---

## 1. 작업 범위

### 포함 범위

1. 업체명과 웹사이트 기반 공개정보 수집
2. 기업 기본정보 구조화
3. 주요 제품·품목군 추출
4. 인증·고객사·시장 정보 추출
5. KOAA SHOW 상담 후보 관점 요약
6. AX 태그 생성
7. 검수 필요 항목 표시
8. Markdown/JSON/CSV 또는 HTML 일부 샘플 제공

### 제외 범위

```text
- 실제 거래 가능성 보장
- 바이어 검증 완료 판정
- 담당자 이메일 확보 보장
- 수입 이력 확정
- HS Code 확정
- 기업 신용평가
- 모든 웹사이트 오류/폐쇄 페이지 수동 보정
```

## 2. 입력 데이터 양식

아인글로벌이 제공해야 할 최소 항목:

| 필드 | 필수 | 예시 |
|---|---|---|
| company_name | 필수 | Shandong Alltour Automotive Co., Ltd. |
| website | 필수 | https://www.alltourbrake.com |
| country | 권장 | China |
| target_region | 선택 | CIS / Uzbekistan / Europe |
| product_group | 권장 | 브레이크 패드 / 제동부품 |
| company_type_hint | 선택 | 제조사 / 바이어 / 유통사 |
| priority | 선택 | High / Medium / Low |
| memo | 선택 | 우즈베키스탄 출장 관련 후보 |

## 6. 비용 메시지 전략

2,000개사는 PoC 후속 검증 차원의 지원으로 진행하되, 1만개사부터는 비용 협의가 필요하다는 메시지를 부드럽게 전달한다.

권장 표현:

```text
2,000개사 파일럿을 통해 수집 성공률, 평균 처리시간, 검수 난이도, API/운영비를 실측하겠습니다.
그 결과를 바탕으로 1만개사 이상 확장 시에는 아인글로벌의 가용 예산 범위에 맞춰 단계별 구축 범위를 제안드리겠습니다.
```

피해야 할 표현:

```text
- 전부 무료로 해드리겠습니다.
- Hermes 설치법을 모두 공유하겠습니다.
- 1만개사도 바로 만들어드리겠습니다.
- 비용은 거의 들지 않습니다.
```
