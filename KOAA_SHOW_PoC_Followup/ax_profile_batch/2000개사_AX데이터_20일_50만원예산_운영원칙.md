## 2. 내부 비용 기준

현재 OpenAI 잔액 약 USD 336.27을 최대 한도로 사용한다.

```text
USD 336.27 × 1,500원 = 약 504,405원
USD 336.27 × 1,550원 = 약 521,218원
```

2,000개사를 모두 처리할 경우 1개사당 평균 허용비용은 다음과 같다.

```text
USD 336.27 / 2,000개사 = 약 USD 0.168 / 개사
환율 1,500원 기준 약 252원 / 개사
환율 1,550원 기준 약 261원 / 개사
```

안전 운영을 위해 90% 한도에서 1차 경고선을 둔다.

```text
90% 한도: USD 302.64
업체당 평균 허용비용: USD 0.151 / 개사
```

```text

```
